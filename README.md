# Nogitsune Development website
This is an implementation of the [express-react-typescript-boilerplate](/TannerHill/express-react-typescript-boilerplate) starter code.

## Features
- ### Backend
    - [Express JS](https://github.com/expressjs/express)
    - [Routing Controllers](https://github.com/typestack/routing-controllers)
    - [TypeDI](https://github.com/typestack/typedi)
    - [Node Mailer](https://github.com/nodemailer/nodemailer)
- ### Frontend
    - [React JS](https://github.com/react/react)
    - [React MUI](https://github.com/mui/material-ui)
    - [React Router](https://github.com/remix-run/react-router)
- ### Fullstack
    - TypeScript (including Shared types)
    - Docker
---
Once deployed, this website will be available at https://nogitsune.dev
